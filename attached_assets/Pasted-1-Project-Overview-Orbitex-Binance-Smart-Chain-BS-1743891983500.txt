1. Project Overview

Orbitex एक क्रिप्टो टोकन इन्वेस्टमेंट प्लेटफॉर्म है, जो Binance Smart Chain (BSC) पर आधारित होगा। यह प्लेटफॉर्म टोकन सेल, स्टेकिंग, मैट्रिक्स लेवल इनकम और रिवार्ड सिस्टम प्रदान करता है। यह Django और Python के बैकएंड सपोर्ट के साथ Solidity का उपयोग करके स्मार्ट कॉन्ट्रैक्ट डेवेलप करेगा।

2. Technology Stack

Frontend:

Django (Template System)

HTML, CSS, Bootstrap

JavaScript (Web3.js for blockchain interaction)


Backend:

Django REST Framework (API Development)

PostgreSQL / MySQL (Database Management)

Celery + Redis (Background Jobs Processing)

Web3.py (Blockchain Communication)


Blockchain (Smart Contracts):

Solidity (Binance Smart Chain Smart Contract Development)

Remix IDE (Smart Contract Testing & Deployment)

BSCScan API (For Contract Verification & Monitoring)

Binance Testnet/Mainnet (For Deployment & Testing)

4. Smart Contract Development (Solidity + Remix)

(A) Orbitex Token (BEP-20 Contract)

Name: Orbitex Token (OBX)

Total Supply: 10 Million OBX

Transfer, Approve, Mint & Burn Functions


Sample Code:

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

import "@openzeppelin/contracts/token/ERC20/ERC20.sol";

contract OrbitexToken is ERC20 {
    address public owner;
    
    constructor() ERC20("Orbitex Token", "OBX") {
        owner = msg.sender;
        _mint(msg.sender, 10000000 * 10 ** decimals());
    }
}
